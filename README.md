# Dé Couleur

Site statique permettant de lancer **2, 3 ou 4 dés de couleur**.

## Nouveautés de la version 1.1

- le bouton **Réglages** n'a plus de flèche ;
- ouverture d'une vraie fenêtre de réglages ;
- catégories visuelles : Profil, Paramètres, Visuel et À propos ;
- les catégories Profil, Paramètres et À propos servent d'interface décorative ;
- le véritable panneau des probabilités se trouve dans **Réglages → Visuel**.

## Probabilités

- **0 %** : la couleur ne peut jamais sortir ;
- **50 %** : poids normal ;
- **75 %** : poids plus élevé ;
- **100 %** : la couleur est garantie au moins une fois.

Il n'est pas possible de garantir plus de couleurs que le nombre de dés.
